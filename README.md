# KIZOREX — Aerotics-inspired engineering website

A distinct, original KIZOREX website inspired by the general industrial-engineering presentation style of the reference site. No source code, brand assets, or photographs from the reference site were copied.

## Preview
Extract the ZIP, open this folder in VS Code, and choose **Open with Live Server** on `index.html`. You can also open `index.html` directly.

## Pages
Home, Services, Industries, Portfolio, Capabilities, About, Contact, Privacy. Each has unique editorial content.

## Assets
Bundled MP4s include user-provided aerospace/network footage and the previously generated KIZOREX conceptual engineering animation. Bundled image files come from your previous KIZOREX project. Their licensing/ownership for commercial use should be confirmed before public deployment. No imagery was copied from Aerotics.

## IMPORTANT BEFORE GOING LIVE
- The quote form uses `mailto:` and opens the visitor's email app. It does not submit server-side.
- The portfolio is intentionally honest: demonstration files are planned but not yet available.
- No unsupported claims of clients, projects, ISO certifications, software licenses, or standards compliance.
- Confirm the brand artwork and industrial images are authorized for commercial use.
- The page loads Google Fonts when online; it falls back to system fonts offline.
- Host on GitHub Pages by uploading the extracted contents to the repository root and enabling Pages. For a custom GoDaddy domain, configure only web DNS records and preserve Zoho MX, SPF, DKIM and DMARC records.
